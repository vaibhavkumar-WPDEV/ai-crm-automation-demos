First 20 hours

Hours 1-4Inventory every workflow, owner, trigger, object and what it changes. Read only, change nothing.
Hours 5-8Reproduce the top issues on a test contact. Rank by customer impact.
Hours 9-14Fix the highest-priority one (duplicate or inappropriate email). Test each path, write the result down.
Hours 15-18Add error alerts and a weekly workflow health check. Check n8n backups, updates and restore steps.
Hours 19-20Handover note: what changed, what is still risky, proposal for the first supervised AI pilot.
